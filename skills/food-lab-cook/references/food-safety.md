# 家庭做法的安全熟度

本节是对书的补充，依据 [FoodSafety.gov 家庭最低内部温度表](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)，核对日期：2026-10-11。它与书中追求特定口感的温度表不是同一用途。网站标注最近审阅日期为 2024-11-21；长期使用或特殊烹调情形时重新核对适用官方资料。

## 普通家庭做法采用的终点

| 食材 | 中心温度或结束条件 |
| --- | --- |
| 鸡、鸭、火鸡等禽肉，包括禽类绞肉 | 达到 74℃ |
| 牛、猪、羊等非禽类绞肉及生香肠 | 达到 71℃ |
| 牛、猪、羊的整块排、烤肉 | 达到 63℃，离火后至少静置 3 分钟 |
| 鱼肉 | 达到 63℃，或鱼肉不再半透明且能用叉子轻易分离 |
| 虾、龙虾、蟹、扇贝 | 肉呈珠白或白色且不透明 |
| 蛋料理 | 达到 71℃；普通整蛋烹调至蛋白、蛋黄凝固 |
| 含肉禽的焗烤菜、复热剩菜 | 达到 74℃ |

温度计探入最厚处，避开骨头，必要时测几处。厚肉的余温升温取决于尺寸和方法，不能据此要求用户低于上述温度取出并假定自然会达标。禽肉混入其他绞肉时，按禽肉要求处理。

计时、外皮颜色、肉汁颜色和手指按压不能单独保证肉禽安全。缺温度计时，给切薄、均匀大小、充分加热的保守方法，并说明时间范围不能验证安全中心温度；不要假称看起来熟就已测得达标。

## 口感目标与低温方法

书中关于半熟蛋、低温鱼肉、低温鸡胸等的讨论，不直接转换成普通锅煎、蒸煮的安全终点。用户明确追求较低温熟度或 sous vide 时，说明时间和温度需要同时满足，还受厚度、起始状态、设备控温及储存影响；核对适用官方时间与温度指南后再给方案。不要复制自制冰桶等实验方法作为常规家庭默认推荐。

有孕妇、幼儿、老人或免疫力低下人群时，选充分加热版本；生蛋酱用巴氏杀菌蛋或成熟商业替代，不能因为乳化成功就认为杀菌完成。

## 只有相关时才补充的边界

- 生肉与即食食材的砧板、刀和容器避免交叉使用；接触过生肉的腌汁未经充分加热不能当成品蘸汁。
- 「绿色、清脆」不是所有蔬菜的安全熟度。四季豆、鲜豆角需充分煮熟；不能把书中甜豆、豌豆的短时处理推广到它们。干豆类需按种类充分处理，未知种类时先确认。依据：[香港食物安全中心：未经烹煮或未煮熟的豆类中的天然毒素](https://www.cfs.gov.hk/sc_chi/multimedia/multimedia_pub/multimedia_pub_fsf_139_04.html)，核对日期：2026-10-11。
- 需要解冻或提前准备时，优先冷藏解冻；不建议长时间室温回温、室温腌制或把整锅炖肉在室温放凉过夜。给保存方案前核对适用保存时限，不能只根据是否闻到异味判断。

日常输出只在相应步骤给必要熟度或一条提示，不把整份安全参考当作每次菜谱的前言。
